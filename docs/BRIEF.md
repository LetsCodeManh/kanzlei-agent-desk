# The assignment

A take-home task, in my words. Build an app that reads a lawyer's inbox and uses AI to make a personal
morning briefing. What goes in it, the stack, the architecture and the UI were my choice. A simulated
inbox with typical Kanzlei emails was enough. My decisions had to be easy to follow: why these features
first, and why this technical route. Not production-ready.

The repo had to hold a short README on how to test it, and the AI prompt history. It holds a summary of
the history instead: `HOW-IT-WAS-BUILT.md`.
